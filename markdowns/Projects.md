# Nock : X11 lockscreen app
A super simple **X11 screen locker app** written in *C*, using **XCB** to talk with the **X Display Server**. It leverages **PAM Management Groups**, and using its own PAM file performs what a lockscreen should do!

# c-ssg
A **static site generator** written in **C** using nothing but standard **POSIX APIs**. It consists of modular code with a seperate `parser` and `reader` files. It also features a top and bottom bar, cleanly listed entries for nested markdown files in the `/markdown` folder, a **theme switcher** button. Supports **meta-data** for each markdown files to decide tags (in the listed entries view) and title of the site.

Oh you want a demo? Well.. this site you're on is built completely using my **c-ssg**!! You are using the demo right now!
